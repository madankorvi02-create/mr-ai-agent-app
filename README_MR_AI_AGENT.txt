MR. AI AGENT - Android starter project

What is included:
- Android app source code using Kotlin + Jetpack Compose
- Prompt input
- Duration selector from 5 to 27 seconds
- Vertical 9:16 format display
- Style selector
- Generate button prototype

Important:
This is Android Studio source code, NOT an installable APK.
The Generate button currently validates the prompt and displays settings.
It does not generate a real video yet.

To build:
1. Install Android Studio on a computer.
2. Open this project folder in Android Studio.
3. Allow Gradle sync to finish.
4. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).

To enable real video generation:
- Choose a video-generation API/provider.
- Create a secure backend server.
- Keep API keys on the server, never inside the Android app.
- Connect the app to that backend.
- Check the provider's pricing, duration limits, licensing and age requirements.

The app is a prototype starter, not a published Play Store app.
